PROJECT / QT / NETWORK

把 TCP 与 UDP 联调，整理成一套清晰的桌面工作台。

网络调试助手是一个基于 Qt Widgets 与 C++17 的桌面项目，采用界面层、服务层和网络后端分离的结构，面向 TCP 服务端、TCP 客户端和 UDP 的连接、收发与状态观察场景。

返回项目区

PREVIEW

主界面预览

CONNECTION

连接配置

连接区统一管理协议、地址和端口参数。TCP 服务端可监听本地地址等待连接，TCP 客户端可连接远端服务，UDP 则按配置完成无连接收发。连接状态会同步到界面控件，断开后发送区也会恢复到安全状态。

TCP 服务端TCP 客户端UDP地址与端口

RECEIVE

实时接收区

接收视图集中展示网络数据，并提供 ASCII、HEX 等显示方式。时间戳与来源开关帮助定位数据到达顺序和对端信息，暂停、清空和导出操作则用于控制当前调试记录。

ASCII / HEX时间戳来源标记导出记录

SEND

发送与自动发送

发送区支持编辑待发内容、选择目标客户端、切换编码模式和设置发送周期。单次发送与自动发送共用网络管理层，连接断开时会停止自动发送，避免继续向无效连接写入数据。

目标选择自动发送周期控制连接联动

ARCHITECTURE

分层实现

网络后端通过统一接口抽象 TCP 服务端、TCP 客户端和 UDP 实现；NetworkManager 负责连接生命周期、数据转发、客户端列表和收发统计；MainWindow 只负责组装界面并连接信号，降低界面与通信细节的耦合。

ui/             MainWindow、连接区、接收区、发送区
service/        NetworkManager 服务层
network/        TCP 服务端、TCP 客户端、UDP 后端
core/           连接配置、全局定义、应用日志

OBSERVABILITY

状态与统计

状态栏持续显示 RX/TX 字节数与数据包数量，错误通过状态消息反馈，日志模块统一接收应用级记录。这些信息适合在联调时快速确认连接是否建立、数据是否真正流动，以及异常发生的位置。

RX / TX 统计客户端列表错误反馈应用日志
