PROJECT / VISION / UARM

相机认颜色、算坐标，串口发给四轴机械臂把圆片分拣开。

用工业相机采集散落在工作台上的彩色圆片，先分离色度与亮度做颜色分类，再用区域处理锁定每颗圆片的中心点，配合手眼标定矩阵把图像坐标换算成机械臂坐标，通过串口把目标坐标下发，由 UARM 四轴机械臂完成抓取与分拣。

FEATURES

核心流程

相机实时采集 → HSV 分离色度与亮度 → 阈值分割 + 形态学处理 → 连通域与中心点提取 → 颜色分类 → 手眼标定换算坐标 → 串口下发机械臂 → 抓取分拣。

IMPLEMENTATION

实现方式（Halcon + 串口）

下面是该项目的主链路，标定矩阵事先离线写入 tup 文件，运行时直接读取复用。

1. read_tuple             读取手眼标定矩阵 HandEyeCalibrationMatrix.tup
2. open_serial            打开串口 COM3
3. set_serial_param       115200, 8, none, none, 1
4. write_serial           下发初始化指令与回零指令 cmd_init / cmd_move_home
5. grab_image_async       通过相机句柄连续取图
6. trans_from_rgb         R,G,B -> H,S,V，色度与亮度解耦
7. binary_threshold       在 V 通道用最大类间方差法分割背景
8. fill_up_shape          填补小面积空洞，去毛刺
9. erosion_circle(120)    腐蚀断开相邻圆片
10. connection            打散连通域
11. dilation_circle(120)  等半径膨胀还原形状
12. intersection          与填充区域求交，得到每颗圆片
13. area_center           取面积与中心坐标，用于分类与定位
14. write_serial          把目标坐标写入串口，驱动机械臂抓取
