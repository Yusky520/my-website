PROJECT / QT / C++

把五子棋做成一个完整的本地对战体验。

GobangChess 是一个基于 Qt Widgets 和 C++17 的桌面五子棋项目，重点练习界面组织、棋盘绘制、规则判断和简单 AI 对战。

FEATURES

功能概览

支持双人对战和人机对战，可选择 AI 难度、执棋颜色与规则模式；对局中提供重新开始、悔棋、退出和回合倒计时。

双人对战人机对战悔棋倒计时

IMPLEMENTATION

实现方式

使用 Qt Widgets 构建页面，C++17 组织棋盘数据、落子校验、胜负判断和候选落子搜索。项目以本地桌面程序形式运行，不依赖在线服务。

1. Qt Widgets 搭建设置页与棋盘页
2. 自定义 BoardWidget 绘制棋盘
3. 处理规则校验与五连判断
4. 使用候选落子与搜索完成 AI 回合
