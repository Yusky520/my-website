PROJECT / VISION / MEASUREMENT

把像素变成有意义的数值：卡尺测量、圆心拟合与仪表读数。

这一组是尺寸测量方向的练习：先用形状模板匹配把工件摆正，再用亚像素边缘与卡尺工具测量尺寸，或用拟合直线与圆求交点与夹角；另外做了指针式仪表的自动读数，把指针角度换算成刻度值。

返回项目区

NUT MEASURE

六角螺母数量与边长测量

自动统计六角螺母数量（4 个），并对每个螺母测量对边/对角尺寸，直接标在图上（如 95.8497 pixel）。

METER READING

指针式电压表自动读数

提取表盘与刻度、拟合指针直线，按刻度换算读数，识别结果 9.74768 V。

LOCATE

标签定位与十字标注

对细长标签做定位，输出中心点与姿态，并用十字线标注方向，便于后续抓取或贴合。

IMPLEMENTATION

实现方式（测量链路）

测量类任务的关键是先把工件摆正，再在正确的坐标系里量尺寸——否则数值没有意义。

1. create_shape_model     建模板（可按需用 create_scaled_shape_model 支持缩放）
2. find_shape_model       定位并得到 Row / Column / Angle
3. vector_angle_to_rigid  由位姿生成齐次矩阵
4. affine_trans_region    把预先框好的测量 ROI 跟着工件一起摆正
5. reduce_domain          在摆正后的 ROI 里处理
6. edges_sub_pix          亚像素边缘提取，精度优于像素级
7. segment_contours_xld   把轮廓打断成直线段/圆弧段
8. fit_line_contour_xld   直线拟合
9. fit_circle_contour_xld 圆拟合
10. gen_measure_rectangle2 / gen_measure_arc  生成卡尺
11. measure_pairs         卡尺测量边缘对，得到宽度/间距
12. angle_ll / distance_pp / intersection_*   求夹角、距离与交点
