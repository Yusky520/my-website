PROJECT / VISION / HALCON

逐根量引脚宽度，少一根就判 NG 并说清缺几根。

两档三脚卧式开关的引脚测量与缺陷检测：先定位开关本体，再把测量区域摆正，逐根引脚测量宽度并统计 平均宽度与引脚间距；同时统计引脚数量，数量不足时判 NG 并输出缺失根数——测量与缺陷判定在同一套流程里完成。

返回项目区

PIN MEASURE · OK

逐根引脚测量（样本一）

逐根标注引脚宽度（20.7644 / 20.2307 / 20.0577 pixel 等），并输出引脚平均宽度 20.3493 pixel、引脚之间平均间距 71.9762 pixel，判定 OK。

PIN MEASURE · OK

逐根引脚测量（样本二）

换一个摆放姿态后同样稳定：平均宽度 20.4208 pixel、平均间距 72.5219 pixel，判定 OK。

DEFECT · NG

引脚缺失判定

引脚数量不足时直接判 NG 并输出「引脚缺失：2 根」，把缺陷类型与数量一起给出来。

逐根引脚宽度测量、平均宽度与平均间距统计、引脚数量计数与缺失判定、OK / NG 结果与缺陷明细输出。
