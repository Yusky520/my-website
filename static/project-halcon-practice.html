PRACTICE / VISION / HALCON

Halcon 算子练习集：从区域分割到字符识别与缺陷检测。

按天记录的 Halcon 练习，共 10 组、27 个案例。覆盖区域分割与特征筛选、颜色空间与颜色分类、形状模板匹配定位、OCR 字符识别、表面缺陷检测与计数测量。每组都是先想清楚判定思路，再动手写算子，最后把结果画回图像上确认。

OVERVIEW

练习覆盖范围

练习集中在工业视觉最常用的几类算子上：图像读取与预处理、阈值分割与 Blob 特征筛选、颜色空间转换与颜色分类、形状模板匹配与位姿矫正、亚像素轮廓与拟合、OCR 字符识别、一维码与二维码识别，以及单相机标定与九点标定。

CATEGORIES

按方向归类

27 个案例按判定目标分成四类，下面的每组结果图标注了它对应的方向。

计数与测量有无与极性判别字符识别表面缺陷检测颜色分类运动目标

D3 · 计数与图像运算

统计 1 块钱硬币 / 识别骰子点数 / 图像合成

用分割 + 连通域做计数，并练习两幅图之间的合成运算。

D4 · 有无与方向判别

识别有无工件 / 识别有无（画矩形交集）/ 回形针指向

最简单的一类判定：区域是否命中 ROI。用矩形交集做有无判断，再用轮廓方向判断回形针朝向。

D6 · 极性与字符

判断电池正反 / 工件 / 提取瓶盖上的字

按特征差异判定电池正反，并从瓶盖表面提取字符区域。

D7 · 仪表与字符识别

电压表检测（课堂演练）/ 电压识别 / 识别酒瓶字符

指针式仪表的读数思路，以及瓶身字符的定位与识别。

D8 · 字符识别

易拉罐底部点印字符识别 / 点数字 / 铭牌识别

点印字符对比度低、铭牌字符排列规律，两种情况分别处理。

D9 · 颜色分类与计数

圆片颜色个数 / 保险丝颜色检测

转到颜色空间后按色度分类，再对每类分别计数。

D10 · 缺陷、计数与字符

刻章缺陷检测 / 螺丝计数 / 牛奶标签识别

同一组里对比了缺陷判定、数量统计与标签字符识别三种任务。

D11 · 运动目标与缺陷

框出运动对象 / 胶囊缺陷检测

用帧间差异框出运动对象，并对胶囊表面做缺陷检测。

D12 · 表面缺陷检测

布匹污渍框选 / 铜箔缺陷检测 / 网格状产品缺陷检测

布匹、铜箔、网格产品的表面缺陷，难点在于纹理本身就会干扰分割。

D13 · 字符识别

瓶盖 / 生产日期

瓶盖表面与喷码生产日期的字符提取，属于产线常见的字符识别场景。

NOTE

关于这些练习

练习图按组记录，每组含 2–3 个案例，图上是该组的运行结果。练习阶段重点关注判定思路是否成立、算子的参数区间如何确定，以及结果能否稳定复现；与实训项目相比，练习更强调算子覆盖的广度。
