PROJECT / QT / C++

把常用文本编辑需求做成一个顺手的桌面记事本。

NotePad 是一个基于 Qt Widgets 和 C++ 的桌面练习项目，围绕文件读写、编辑操作、状态反馈和本地持久化做了完整整理。

FEATURES

核心功能

支持新建、打开、保存、另存为、退出，以及剪切、复制、粘贴、全选、字体设置、清空内容、撤销重做等常用编辑操作。

新建 / 打开 / 保存撤销重做字体设置清空内容

DETAILS

交互细节

未保存内容在新建、打开或关闭窗口前会弹出确认提示；状态栏实时显示行列位置；当前行带高亮；空白文档会根据首行内容动态更新窗口标题。

未保存提示行列状态当前行高亮动态标题

IMPLEMENTATION

实现方式

项目以 QMainWindow 作为主框架，中心区域使用自定义 QPlainTextEdit，文件操作基于 QFile、QFileDialog 和 QTextDocument 组织，最近文件记录通过 QSettings 做本地持久化。

1. QMainWindow 搭建菜单栏、工具栏和状态栏
2. QFile / QFileDialog 处理打开、保存、另存为
3. QSettings 维护最近文件与清空记录
4. QTextDocument 联动撤销、重做和修改状态
5. Ctrl + 滚轮实现编辑区字体缩放

HIGHLIGHTS

项目亮点

打开文本时会先尝试 UTF-8 解码，异常时回退到本地编码；重新打开历史文件前会复用未保存检测逻辑；保存后会同步更新文件名标题和最近文件列表。

UTF-8 / Local8Bit最近文件编码兼容本地持久化
