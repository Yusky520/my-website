PROJECT / QT / MULTIMEDIA

把拍照、预览和相册浏览整理成一套轻量顺手的桌面工具。

Camera 是一个基于 Qt Multimedia 和 C++17 的桌面练习项目， 主界面负责摄像头预览与拍照，相册界面负责缩略图浏览、原图切换、 删除与按画质保存，整体围绕拍摄到整理的完整流程展开。

FEATURES

核心功能

支持自动加载摄像头设备、选择不同摄像头、开启与关闭预览、一键拍照、 连续拍照间隔设置，以及拍照后同步把图像推送到相册页进行浏览。

QCamera 实时预览 一键拍照 连续拍照

ALBUM

相册与浏览体验

相册页会把每次拍摄的图片加入横向缩略图列表，支持点击缩略图查看原图、 鼠标滚轮快速切换当前照片、删除选中图片、清空列表，以及自动刷新大图预览。

缩略图列表 滚轮切换 删除选中 清空列表

SAVE FLOW

保存与画质控制

相册页提供保存图片按钮，可通过文件对话框导出 PNG、JPG 或 BMP， 同时用滑块调节 JPG 画质参数，适合在保存前按不同需求控制图像质量。

PNG / JPG / BMP 画质滑块 另存图片 本地相册

IMPLEMENTATION

实现方式

主窗口通过 QMediaCaptureSession 连接 QCamera、QVideoWidget 和 QImageCapture， 负责设备预览与拍照；相册页通过 QListWidget 管理缩略图，通过 QLabel 显示原图， 连续拍照则由 QTimer 按输入间隔触发抓拍。 

1. QMediaDevices 枚举可用摄像头设备
2. QMediaCaptureSession 统一挂接相机、预览窗口与图像捕获
3. QImageCapture 把拍摄结果同时发送到主界面和相册页
4. QTimer 控制连续拍照节奏，默认 33ms 接近 30 帧
5. QListWidget + QLabel 组织缩略图浏览与原图预览

HIGHLIGHTS

项目亮点

预览关闭时会自动断开视频输出并复位连续拍照状态；相册页在窗口显示、 尺寸变化和滚轮切换时都会同步刷新原图显示；拍摄完成后新照片会自动滚动到最新项。

状态联动 自动滚动最新 窗口自适应刷新 Qt Multimedia
