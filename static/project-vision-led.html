PROJECT / VISION / HALCON + QT

用 Halcon 逐颗判定 LED 灯珠，把 OK / NG 结果画回图像并送进 Qt 上位机。

LED 灯板灯珠检测：先由形状模板匹配识别灯板型号，再在 HSV 空间按饱和度阈值分割灯珠区域，用 Blob 特征筛选与计数判断漏贴、错贴，并把每颗灯珠的判定结果直接标注在图像上；上位机侧使用 Qt 承载 Halcon 窗口与算法调用，实现读图、定位与结果输出。

返回项目区

LED BOARD

灯板原图（十灯珠型）

采集原图：同一工位下的灯板照片，模板匹配据此判定灯板型号并给出位姿。

S CHANNEL

HSV 分离出的 S 通道

直接用灰度分割容易被白纸背景带偏，改用饱和度通道后灯珠明显亮于背景。

SEGMENT

阈值 + 特征筛选后的灯珠

S 通道阈值分割 + 连通域，再按面积（8500–10000）与高度筛选，得到 8 颗灯珠。

RESULT

最终标注与判定输出

每颗灯珠用最小外接矩形框出并计数，输出「十灯珠类型 / NG / OK 8 颗 / NG 2 颗」。

QT HOST

Qt 上位机界面

上位机左侧按流程分区：相机初始化、图像采集、传送带初始化（COM6）、在线检测与离线检测；右侧同时显示原始画面与叠加结果，并在画面上直接输出灯盘类型、识别到的灯珠数量与 OK / NG 判定。图中为十灯珠板，判定为 NG。

FEATURES

核心功能

支持两种灯板型号（6 颗 / 10 颗）的模板识别、灯珠区域分割与计数、单颗灯珠 OK / NG 判定与可视化标注；上位机支持相机初始化与单次采图，通过串口（COM6）控制传送带启停，并提供在线检测与离线复检两种模式。

形状模板匹配HSV 颜色空间Blob 分析OK / NG 判定

IMPLEMENTATION

实现方式（Halcon 关键链路）

下面是该项目 Halcon 侧的主要算子调用顺序，模板只用一次 ROI 裁剪即可复用。

1. reduce_domain        裁剪 ROI，只保留模板区域
2. create_shape_model   为「6 灯珠 / 10 灯珠」各建一个形状模板
3. find_shape_models    运行时搜索模板，判定当前灯板型号
4. trans_from_rgb       R,G,B -> H,S,V，把色度与亮度分开
5. threshold            在 S 通道上做 81 ~ 169 阈值分割灯珠
6. connection           打散连通域为单颗灯珠
7. select_shape         按 ['area','height'] 过滤掉噪点与反光
8. count_obj            统计灯珠数量
9. disp_message         数量达标输出 OK，否则输出 NG 与数量明细
