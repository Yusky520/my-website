PROJECT / VISION / HALCON

判有无、提圆心、算共线与旋转量——把几何关系量出来。

圆柱孔配件检测：先用形状模板匹配定位配件并判定有无，没有工件就直接输出 NG； 再对灰度图做阈值分割，用面积与圆形度筛选出各个圆孔，通过最小外接圆拟合圆心； 最后把五孔圆心拟合成直线求共线偏差，并用 angle_ll 计算工件绕其中心的旋转量。

FEATURES

核心功能

配件有无判定（无件直接 NG）、圆孔区域提取与圆形度筛选、最小外接圆圆心拟合、五孔共线偏差计算、工件绕中心旋转量输出，结果全部标注回原图。

模板匹配Blob 筛选最小外接圆共线度旋转量

IMPLEMENTATION

实现方式（Halcon 关键链路）

难点在于圆孔灰度对比度低、多孔同时提取容易串，以及圆心误差会直接影响角度计算——所以圆心用最小外接圆拟合，共线用直线拟合计算。

1.  gen_circle                  在模板图上框出手工 ROI（只做一次）
2.  reduce_domain               只在 ROI 内建模板，避免背景干扰
3.  create_shape_model          训练配件形状模板
4.  find_shape_model            运行时定位；无结果即为「未检测到配件」
5.  threshold (0 ~ 74)          圆孔偏暗，用低灰度阈值分割
6.  connection                  连通域打散
7.  select_shape ['area','circularity']
                                用面积 + 圆形度筛出各圆孔
8.  select_shape (area 75000~80000)
                                单独取出中心大孔
9.  smallest_circle             最小外接圆拟合，得到圆心 Row / Column
10. gen_cross_contour_xld       在每个圆心上画十字标注
11. gen_contour_polygon_xld     把参与共线的圆心连成直线
12. angle_ll                    计算共线直线夹角 -> 工件绕中心的旋转量
