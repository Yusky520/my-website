PROJECT / VISION / HALCON

一次拍多个工件，长宽和孔径逐个量完并换算成毫米。

圆角矩形金属背板尺寸测量：先用形状模板匹配定位工件，得到位姿后把预先框好的测量 ROI 跟着工件一起摆正，再用一维测量卡尺取边缘对，测出高度、宽度与孔径，按像素当量换算成毫米输出； 同一画面里有几个工件就量几个，没有工件时输出 0 个，不进入测量。

返回项目区

匹配到的目标个数：1 个

高 39.9636 mm、宽 19.9729 mm、孔径 9.2944 mm，红色为高度、蓝色为宽度、绿色为孔径标注。

视野内没有工件时输出 0，不产生任何测量值，避免用错误数据放行产品。

MULTI TARGET

匹配到的目标个数：2 个

一次拍摄同时测量两个工件并分别输出：高 39.9995 / 40.1021 mm，宽 19.9047 / 19.9915 mm，孔径 9.08141 / 9.1214 mm。

FEATURES

核心功能

多目标匹配与计数、任意角度位姿矫正、高度 / 宽度 / 孔径三个尺寸一次测量、毫米单位输出；工件数量为 0 时直接跳过测量。

多目标匹配位姿矫正卡尺测量毫米输出

IMPLEMENTATION

实现方式（Halcon 关键链路）

关键点是"测量 ROI 跟着工件走"：先用模板匹配拿到每个工件的位姿，再把预先标好的 ROI 用同一个位姿矩阵摆正，这样工件怎么摆都不影响测量。

1.  gen_rectangle* / gen_circle     在模板图上框好 4 个参考 ROI
                                     （整体、高、宽、孔径）
2.  area_center                     记录每个 ROI 的中心点作为参考点
3.  reduce_domain + create_shape_model
                                    只在 ROI 内训练形状模板
4.  list_files / read_image         遍历样本图片批处理
5.  find_shape_model                一次匹配出所有目标：
                                    返回 Row[] / Column[] / Angle[] 数组
6.  vector_angle_to_rigid           用参考点 + 匹配位姿生成齐次矩阵
7.  affine_trans_region             把 4 个 ROI 按位姿摆正
8.  reduce_domain                   在摆正后的 ROI 内处理
9.  gen_measure_rectangle2          生成卡尺（矩形/圆弧测量框）
10. measure_pairs                   取边缘对，得到像素宽度
11. 像素当量换算                    换算成毫米输出到图像上
Halcon一维测量卡尺多目标
