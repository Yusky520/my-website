关于我

PROFILE

从视觉算法到桌面软件：机器视觉方向

我在系统学习机器视觉与桌面软件开发：用 Halcon 做工业视觉算法（模板匹配、Blob 分析、亚像素测量、相机与手眼标定），用 C++ / Qt 做上位机界面，并把实训项目与算子练习整理成可回看的记录。

实训项目包括 LED 灯板灯珠检测、圆柱孔配件共线与旋转量检测、金属背板多目标尺寸测量、开关引脚测量与缺陷检测，以及相机 + 机械臂的彩色圆片分拣联调；同时用 Python / OpenCV / YOLOv8 补深度学习方向的基础。

资料来源 B站、C语言中文网、菜鸟编程、开发者导航、其他
现在的方向 机器视觉算法（Halcon）、Qt / C++ 上位机、相机与机械臂联调
已完成 7 个机器视觉项目的整理与展示：LED 灯板检测、圆柱孔共线检测、机械臂分拣、尺寸测量、背板多目标测量、开关引脚检测与算子练习集。
后续优先沉淀可运行的视觉算法、上位机与硬件联调案例。
