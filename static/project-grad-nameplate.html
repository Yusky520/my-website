PROJECT / VISION / GRADUATION

相机读铭牌，串口调度传送带，自绘采集板回传环境数据。

毕业设计。工业相机采集电机铭牌，Halcon 先用形状模板匹配找到铭牌并按其位姿把图像摆正，再在固定 ROI 里做暗字动态阈值分割，汉字送自建样本训练出的 MLP 模型、数字与字母送工业字库，逐字识别后拼回型号、编号、功率、电压等字段；Qt 上位机同时管离线图片、在线相机与批量文件夹三条入口，结果进表格可搜索可导出；串口按 ASCII 协议与传送带通讯，物体到位停带、抓稳定帧、识别完再放行；STM32 采集板（自绘 PCB）把温度、湿度、相对浓度与震动状态经 HC-06 蓝牙回传，屏幕与上位机两头都能看。

字符框按识别置信度着色（绿 ≥ 0.90、黄 ≥ 0.70、红 < 0.70），一眼就能看出哪几个字需要人工复核；左侧同时挂着海康 GigE 相机与传送带串口（COM3 已连接，日志里 CSD_ON / CSD_OFF 是停带取帧的握手）。

BATCH

批量识别：19 / 69，失败 0 张

批量入口一次选一批图跑完入库：日志「批量识别被中断，已处理 19 / 69」「成功 19 张，失败 0 张」；右侧按品牌 / 型号 / 编号落库，可查看详情、全选、导出、删除，重复样本会连续识别成多条便于对账。

STM32

采集端实物与屏幕显示

STM32F103C8T6 最小系统 + MQ-2 可燃气体 / 烟雾传感器 + 蜂鸣器 + 震动检测 + ST7789 SPI 彩屏，屏幕用八脚排针（GND / VCC / SCL / SDA / RST / DC / GND / BL）接在板上；屏上直接显示「ENV MONITOR / 温度 27 ℃ 湿度 37 % / 相对浓度 3 % 状态 正常 TH60 % / 设备震动正常 / 软件 已连接 HC06」，数据经 HC-06 蓝牙串口发给上位机。

PCB

采集板 PCB

采集板是自己画的（立创 EDA）：STM32 双列排针、两路 15 k / 10 k 分压、DHT-11 温湿度与 SW-420 震动接口、MQ-2 烟雾与 HC-06 蓝牙座、ST7789 彩屏八脚排针、蜂鸣器加蜂鸣器 / MQ / 电源三个拨动开关、LED-B / LED-MQ / LED-STM 三颗状态灯和稳压输出端子；顶部标了 15.4 mm 的排针间距用来校核插装，红蓝两色是双面板上下两层走线。

OCR MODEL

自建汉字样本集

工业字库不认品牌名里的汉字，于是把铭牌上高频出现的 14 类字（中南北大安微晟机江电皖苏驱龙）逐类裁样本，共 112 张、每类 5–13 张，灰度归一化后训练 MLP，导出 dianji.omc 给 do_ocr_multi_class_mlp 调用；数字与字母仍走 Industrial_0-9A-Z_NoRej.omc。

PIPELINE

核心流程

相机采集 → 形状模板匹配定位铭牌并算出角度 → 仿射矫正把铭牌摆正到画面中心 → 分区 ROI（汉字区 / 型号 / 功率 / 参数行）→ 暗字动态阈值分割 + 高度特征筛选切出单字 → 排序成阅读顺序 → 汉字与数字分别走两个 OCR 模型 → 字段拼装、写表、导出。

关键思路是"先摆正、再切字"：模板匹配一旦把位姿校正掉，后面每个 ROI 都是固定坐标，切字只需调阈值，不用再为摆放角度发愁。

IMPLEMENTATION

实现方式（Halcon 主链路）

下面是识别主链路，括号里的参数取自项目脚本。

1.  read_image                  读入标准铭牌图
2.  reduce_domain               圈出铭牌区域
3.  create_shape_model          建形状模板
4.  find_shape_model            每帧先定位，得到 Row / Column / Angle
5.  vector_angle_to_rigid       按位姿把铭牌摆正到画面中心
6.  affine_trans_image          仿射变换后，ROI 位置就固定了
7.  reduce_domain × N           汉字 / 型号 / 功率 / 参数行各一块 ROI
8.  dyn_threshold (…, 47~50, 'dark')   暗字分割，抑制反光
9.  connection + select_shape   按高度 38~43 筛掉噪点与粘连
10. sort_region                 按 column 或 character + row 排阅读顺序
11. read_ocr_class_mlp          dianji.omc / Industrial_0-9A-Z_NoRej.omc
12. do_ocr_multi_class_mlp      逐字输出 Class + Confidence
