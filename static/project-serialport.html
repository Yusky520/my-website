PROJECT / QT / SERIAL

把日常串口联调整理成一套更顺手的桌面调试助手。

SerialPort 是一个基于 Qt Widgets、QSerialPort 和 C++17 的本地桌面工具， 重点围绕串口连接、收发调试、定时发送、多命令循环发送以及日志留存做了完整整理。

主界面预览

FEATURES

核心功能

支持串口列表自动刷新、波特率与数据位设置、打开与关闭串口、 十六进制接收、十六进制发送、发送与接收时间戳显示、单条发送以及接收区保存。

自动刷新串口 HEX 收发 时间戳显示 保存接收日志

WORKFLOW

发送与历史管理

单条发送区域支持 Ctrl + Enter 快捷发送，可选定时发送周期； 历史记录区支持导入、导出和清空；状态日志会按时间持续记录串口状态、 收发结果和异常信息，方便后续回看联调过程。

Ctrl + Enter 历史导入导出 状态日志 单条定时发送

MULTI SEND

多文本循环发送

多文本发送表格可为每一行分别设置启用状态、HEX 模式、发送间隔、备注和发送内容， 程序会自动跳过未启用或空内容项，按顺序循环发送，适合固定指令集联调。

逐行间隔控制 循环多发 备注管理 异常自动停发

IMPLEMENTATION

实现方式

项目以 QMainWindow 组织整体布局，串口通信由 QSerialPort 负责， 串口列表通过 QSerialPortInfo 定时刷新；单条定时发送与多文本循环发送分别由 QTimer 驱动， 文件导入导出则基于 QFile 与 QFileDialog 完成。 

1. QSerialPort / QSerialPortInfo 处理串口连接与端口枚举
2. QTimer 管理单条定时发送与多文本循环发送
3. QPlainTextEdit / QTextEdit 承载收发区、历史区与状态日志
4. QTableWidget 组织多文本命令、间隔、HEX 与备注配置
5. QFileDialog + QFile 完成接收日志保存与历史导入导出

HIGHLIGHTS

项目亮点

串口异常发生时会自动停止定时发送与多发流程，并恢复按钮状态； 发送内容在 HEX 模式下会先校验格式再写入串口； 程序启动后每 500ms 自动刷新串口列表，更贴合真实硬件联调场景。

异常联动处理 HEX 格式校验 500ms 自动刷新 桌面联调工具
